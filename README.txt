E-COMMERCE RECOMMENDATION ENGINE
Using Query Optimization Techniques

SETUP (Windows / VS Code):
1. Extract this ZIP into a folder.
2. Open the extracted folder in VS Code.
3. Open Terminal > New Terminal.
4. (Optional) Create a virtual environment:
   python -m venv .venv
   .venv\Scripts\activate
5. Install requirements:
   pip install -r requirements.txt
6. Run:
   python app.py
7. Open this address in your browser:
   http://127.0.0.1:5000

The SQLite database (ecommerce.db) is created automatically on first run.

Pages:
- Home: browse/search/filter products
- Product details: category-based recommendations
- Cart: add and remove products
- Query Optimization: SQLite execution plan and techniques

This is a learning/demo project, not a production shopping system.
